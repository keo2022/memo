# 엑셀 메모 앱

폰에서 메뉴별로 시트를 만들고, 셀에 값이나 `=SUM(A1:A3)` 같은 간단한 수식을 넣어볼 수 있는
"엑셀의 앱화" 컨셉 프로젝트입니다.

이 앱은 **백엔드 서버가 필요 없습니다.** 데이터는 폰에 내장된 SQLite DB에 저장되며,
빌드된 APK 파일 하나만 폰에 설치하면 완전히 독립적으로 동작합니다 (PC나 Wi-Fi 연결 불필요).

## 구조

```
backend/   (더 이상 사용하지 않음 — 예전 실험용 Node.js API 서버, 참고용으로만 남겨둠)
frontend/  React Native + Expo 앱 (메뉴 목록 -> 시트 목록 -> 시트(그리드) 화면)
           데이터는 frontend/src/db 아래 expo-sqlite로 폰에 직접 저장/계산됩니다.
```

- **메뉴(Menu)**: 카테고리 (예: 가계부, 운동일지)
- **시트(Sheet)**: 메뉴 안에 여러 개 만들 수 있는 표
- **셀(Cell)**: 값 또는 `=`로 시작하는 수식. 지원 함수는 `SUM`, `AVERAGE`, `MAX`, `MIN`, 연산자는 `+ - * / ()`
- 데이터는 폰 안의 SQLite DB(`excel_memo.db`)에 저장되어, 앱을 지우지 않는 한 유지됩니다.

## 0. 사전 준비

1. [Node.js LTS](https://nodejs.org) 설치 (npm 포함) — 이미 설치돼 있다면 생략
2. 무료 [Expo 계정](https://expo.dev/signup) 생성 (APK를 클라우드에서 빌드하기 위해 필요)

## 1. 개발 중 미리보기 (선택)

APK를 빌드하기 전에 PC에서 바로 화면을 확인하고 싶다면 Expo Go로 미리 볼 수 있습니다.

```powershell
cd frontend
npm install
npm run start
```

터미널에 뜨는 QR 코드를 폰의 **Expo Go** 앱으로 스캔하면 실행됩니다.
(이 미리보기 모드에서도 DB는 폰 내장 SQLite를 사용하므로 별도 서버 설정이 필요 없습니다.)

## 2. 설치 파일(APK)로 빌드하기

QR 스캔 없이, 파일을 폰에 내려받아 탭 한 번으로 설치하는 방식입니다.

```powershell
cd frontend
npm install -g eas-cli   # 최초 1회만
eas login                # Expo 계정으로 로그인 (최초 1회)
eas build:configure      # 최초 1회: 프로젝트를 Expo 계정에 연결 (프롬프트에 Enter로 진행)
eas build -p android --profile preview
```

- 빌드는 Expo의 클라우드 서버에서 진행되며 보통 5~15분 정도 걸립니다.
- 완료되면 터미널과 [expo.dev](https://expo.dev) 대시보드에 **다운로드 링크(QR 포함)** 가 나타납니다.
- 폰에서 그 링크를 열어 `.apk` 파일을 다운로드한 뒤, 알림창에서 탭하면 설치됩니다.
  - 처음 설치 시 "출처를 알 수 없는 앱 설치 허용"을 묻는 안내가 뜨면 허용해주세요.
- 이후로는 이 APK가 폰에 남아있는 독립 앱이라, PC를 켜지 않아도 실행됩니다.

### 앱을 업데이트하고 싶을 때

코드를 수정한 뒤 위 `eas build -p android --profile preview` 명령을 다시 실행하고,
새로 나온 APK를 다시 설치(덮어쓰기)하면 됩니다. 기존 데이터는 SQLite 파일에 남아있으므로 유지됩니다.
(단, `app.json`의 `android.versionCode`를 올리지 않아도 재설치는 되지만, 관례상 배포할 때마다 1씩 올려주는 것이 좋습니다.)

## 3. 사용 흐름

1. 앱 실행 → 메뉴 목록 화면에서 메뉴 추가 (예: "가계부")
2. 메뉴 클릭 → 시트 목록에서 시트 추가 (예: "8월")
3. 시트 클릭 → 그리드가 나오고, 셀을 탭하면 값/수식 입력 가능
   - 예: A1에 `10`, A2에 `20`, A3에 `=SUM(A1:A2)` 입력 시 30 표시

## 다음에 채워나갈 수 있는 것들

- 더 많은 엑셀 함수 (IF, COUNT 등)
- 셀 서식(굵게, 색상), 행/열 추가·삭제
- 메뉴/시트 삭제·수정, 정렬
- 여러 폰 간 동기화가 필요해지면 그때 클라우드 백엔드를 다시 고려
